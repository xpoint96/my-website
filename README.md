# Стартовый сайт

## Файлы
- `index.html` — страница, стили и логика.
- `design.csv` — тексты и цветовые настройки сайта.

## Как посмотреть на Mac
1. Распакуй архив.
2. Для проверки открой папку в VS Code.
3. Запусти локальный сервер, например расширением **Live Server** в VS Code.
   Важно: если открыть `index.html` двойным щелчком, браузер может заблокировать загрузку CSV из-за ограничений безопасности.
4. Открой локальный адрес, который покажет Live Server.

## Как опубликовать через GitHub Pages
1. Создай новый публичный репозиторий на GitHub.
2. Загрузи `index.html`, `design.csv` и `README.md` в корень репозитория.
3. Открой **Settings → Pages**.
4. В разделе сборки выбери **Deploy from a branch**, затем ветку `main` и папку `/ (root)`, нажми **Save**.
5. Подожди публикации — GitHub покажет ссылку на сайт в разделе Pages.

## Как менять оформление
Измени значения в `design.csv`. Сохраняй заголовок `key,value` и не удаляй строки с ключами. Для сложного текста с запятыми этот простой CSV-парсер потребует доработки; в текущем шаблоне значения без запятых работают лучше всего.

CSV хранит данные и настройки, а не сами изображения. Если захочешь добавить фото, положи их в папку `images/` и подключи из HTML.
